# 힘찬짐 직원용 어드민

Next.js로 만든 운영 화면입니다. 전체 회원과 이용권 판매 내역을 조회하고, 수업 상태와 운동 메모를 관리합니다. 14일 안에 만료되는 이용권과 이번 달 트레이너별 완료 수업 수를 확인할 수 있습니다.

관리자는 직원 계정을 생성하고 수정하거나 중지할 수 있습니다. 비밀번호를 리셋하면 임시 비밀번호를 화면에 한 번 표시하며, 해당 직원은 다음 로그인에서 비밀번호를 바꿔야 합니다. 트레이너의 근무 요일과 이용권 종류도 관리자가 등록합니다.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

기본 포트는 3001입니다. `BACKEND_URL`에 회원 웹과 동일한 NestJS 백엔드 주소를 넣습니다. Vercel에는 회원 웹과 별도의 Next.js 프로젝트로 배포합니다.

확인용 관리자 비밀번호는 이 저장소에 적지 않습니다. 제출 폼에서 별도로 전달해야 합니다.

디자인은 [getdesign.kr의 뱅크샐러드 DESIGN.md](https://www.getdesign.kr/services/banksalad/DESIGN.md)를 적용했습니다. 원문을 포함했으며 카탈로그 콘텐츠는 CC BY 4.0입니다. 뱅크샐러드와 제휴한 서비스가 아닙니다.
